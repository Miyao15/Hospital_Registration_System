三、关键技术问题及解决方案

3.1 并发预约号源扣减问题

问题描述：多个用户同时预约同一时段时，可能出现超卖现象。

解决方案：使用JPA乐观锁机制

// TimeSlot实体添加版本号字段
@Version
@Column(nullable = false)
private Integer version = 0;

// 扣减号源时自动检查版本号
@Transactional
public void decrementSlot(String timeSlotId) {
    TimeSlot slot = timeSlotRepository.findById(timeSlotId)
        .orElseThrow(() -> new RuntimeException("时段不存在"));
    if (slot.getRemainingSlots() <= 0) {
        throw new RuntimeException("号源已满");
    }
    slot.setRemainingSlots(slot.getRemainingSlots() - 1);
    timeSlotRepository.save(slot); // 乐观锁自动检查
}

3.2 JWT认证与Spring Security集成

问题描述：Spring Security 6.x配置方式变化大，与JWT集成复杂。

解决方案：自定义JWT过滤器

@Component
public class JwtAuthenticationFilter extends OncePerRequestFilter {
    @Override
    protected void doFilterInternal(HttpServletRequest request,
            HttpServletResponse response, FilterChain chain) {
        String token = extractToken(request);
        if (token != null && jwtUtil.validateToken(token)) {
            String userId = jwtUtil.getUserIdFromToken(token);
            UsernamePasswordAuthenticationToken auth = 
                new UsernamePasswordAuthenticationToken(userId, null, authorities);
            SecurityContextHolder.getContext().setAuthentication(auth);
        }
        chain.doFilter(request, response);
    }
}

3.3 Docker部署CORS跨域问题

问题描述：前端容器访问后端容器时出现CORS错误。

解决方案：配置Spring Security允许跨域

@Bean
public CorsConfigurationSource corsConfigurationSource() {
    CorsConfiguration config = new CorsConfiguration();
    config.setAllowedOrigins(Arrays.asList(
        "http://localhost:8081",
        "http://152.136.13.236:8081"
    ));
    config.setAllowedMethods(Arrays.asList("GET","POST","PUT","DELETE"));
    config.setAllowCredentials(true);
    config.setAllowedHeaders(Arrays.asList("*"));
    UrlBasedCorsConfigurationSource source = new UrlBasedCorsConfigurationSource();
    source.registerCorsConfiguration("/**", config);
    return source;
}

3.4 AI接口调用优化

问题描述：通义千问API响应较慢，用户体验差。

解决方案：前端实现打字机效果，后端设置超时

// 前端打字机效果
const typeWriter = (text, callback) => {
  let index = 0;
  const timer = setInterval(() => {
    if (index < text.length) {
      callback(text.substring(0, index + 1));
      index++;
    } else {
      clearInterval(timer);
    }
  }, 30);
};

五、实验总结

5.1 项目收获

5.1.1 技术能力提升

  • 后端开发：深入掌握了Spring Boot 3.x框架，包括Spring Security、Spring Data JPA的使用，理解了RESTful API设计规范
  • 前端开发：熟练使用Vue 3组合式API和Element Plus组件库，掌握了Pinia状态管理和Vue Router路由配置
  • 数据库设计：学会了规范的数据库设计方法，包括ER图绘制、表结构设计、索引优化等
  • 容器化部署：掌握了Docker和Docker Compose的使用，能够实现应用的容器化部署
  • AI集成：学会了调用大语言模型API，实现智能问答功能

5.1.2 工程能力提升

  • 项目管理：学会了使用增量迭代开发模型，合理分解任务，控制项目进度
  • 文档编写：掌握了软件工程文档的编写规范，包括需求文档、设计文档、测试文档等
  • 问题解决：培养了独立分析和解决技术问题的能力，学会了查阅文档和搜索解决方案
  • 版本控制：熟练使用Git进行代码版本管理

5.2 存在不足

  • 功能方面：暂未实现短信验证、在线支付等功能，系统功能还可进一步完善
  • 性能方面：未进行大规模并发测试，系统在高并发场景下的表现有待验证
  • 安全方面：安全措施相对基础，可以增加更多安全防护机制
  • 移动端：虽然支持响应式布局，但移动端体验还可以进一步优化
  • 测试覆盖：单元测试覆盖率不够高，可以增加更多自动化测试

5.3 改进方向

  • 增加短信验证码功能，提升账户安全性
  • 集成在线支付功能，支持挂号费在线支付
  • 开发原生移动端APP，提升移动端用户体验
  • 引入Redis缓存，提升系统性能
  • 增加单元测试和集成测试，提高代码质量
  • 实现消息推送功能，及时通知用户预约状态变化
  • 增加数据统计分析功能，为医院运营决策提供支持

5.4 心得体会

通过本次医院预约挂号系统的开发，我深刻体会到了软件工程的重要性。一个完整的软件项目不仅仅是编写代码，更需要规范的需求分析、系统设计、测试验证和文档编写。

在开发过程中，我遇到了很多技术难题，如并发控制、跨域问题、容器部署等。通过查阅文档、搜索资料、反复调试，最终都找到了解决方案。这个过程虽然艰辛，但也让我收获了宝贵的经验。

前后端分离的开发模式让我对现代Web应用架构有了更深入的理解。Spring Boot和Vue的组合确实能够高效地开发出功能完善的Web应用。Docker容器化部署也大大简化了应用的部署和运维工作。

总的来说，这次实验让我将课堂上学到的理论知识应用到了实际项目中，不仅提升了技术能力，也培养了工程思维和解决问题的能力。这些经验将对我今后的学习和工作产生积极的影响。
