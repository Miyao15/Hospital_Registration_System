医院预约挂号系统
项目开发计划书

1. 概述

1.1 项目的目的与目标

1.1.1 项目目的

随着医疗资源需求的不断增长，传统的现场排队挂号方式已无法满足患者的就医需求，存在排队时间长、号源分配不均、信息不透明等问题。本项目旨在开发一套医院预约挂号系统，通过信息化手段优化医疗资源配置，提升患者就医体验，提高医院运营效率。

1.1.2 项目目标

本项目的具体目标如下：

表1-1 项目目标分解表

目标编号 目标描述 可度量指标 对应功能
G1 实现在线预约挂号 支持7×24小时在线预约 预约挂号模块
G2 提供多角色用户管理 支持患者、医生、管理员三种角色 用户认证模块
G3 实现医生排班管理 支持按日期、时段设置排班 排班管理模块
G4 提供智能问诊服务 AI响应时间<5秒 AI智能助手模块
G5 实现科室信息管理 支持科室增删改查 科室管理模块
G6 提供消息通知功能 预约成功后即时通知 通知消息模块

G8 实现容器化部署 支持Docker一键部署 部署运维

2. 可行性分析

2.1 社会可行性

2.1.1 政策法规

本系统开发符合国家"互联网+医疗健康"政策导向，遵循《中华人民共和国网络安全法》、《个人信息保护法》等法律法规要求，对用户个人信息进行加密存储和传输。

2.1.2 安全因素

表2-1 安全措施表

安全风险 应对措施
用户密码泄露 采用BCrypt加密存储，不存储明文密码
SQL注入攻击 使用JPA参数化查询，防止SQL注入
XSS跨站脚本 前端输入过滤，后端输出转义
未授权访问 JWT Token认证，角色权限控制
暴力破解 登录失败5次锁定账户30分钟

2.1.3 环境因素

系统采用云服务器部署，无需购置物理服务器，减少能源消耗和电子废弃物产生，符合绿色环保理念。

3.2 选定方案

经过综合评估，选择方案A作为本项目的技术方案，理由如下：

  • Spring Boot生态成熟，文档丰富，问题易于解决
  • Vue 3学习曲线平缓，开发效率高
  • MySQL使用广泛，运维成本低
  • Docker Compose部署简单，适合中小型项目
  • 团队成员对Java和Vue技术栈更为熟悉
