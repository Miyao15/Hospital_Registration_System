3. 数据结构设计

3.1 持久类分析

本系统采用JPA/Hibernate作为ORM框架，所有实体类均使用@Entity注解标记为持久类，通过@Table注解映射到数据库表。主要持久类包括：

  • User：用户基础表，存储所有用户的登录凭证，通过role字段区分角色
  • Patient：患者信息表，通过user_id外键关联User表
  • Doctor：医生信息表，通过user_id外键关联User表，department_id关联科室
  • Department：科室表，独立实体，被Doctor引用
  • Schedule：排班表，通过doctor_id关联医生
  • TimeSlot：时段表，通过schedule_id关联排班，使用@Version实现乐观锁
  • Appointment：预约表，关联患者、医生、时段等多个实体

3.6 存储过程与触发器设计

本系统采用JPA/Hibernate框架进行数据访问，主要业务逻辑在Service层实现，未使用数据库存储过程。以下为系统中的关键业务逻辑说明：

3.6.1 预约号源扣减逻辑

采用乐观锁机制（@Version注解）防止并发超卖：

// TimeSlot实体使用@Version实现乐观锁
@Version
@Column(nullable = false)
private Integer version = 0;

// Service层扣减号源
@Transactional
public void decrementSlot(String timeSlotId) {
    TimeSlot slot = timeSlotRepository.findById(timeSlotId)
        .orElseThrow(() -> new RuntimeException("时段不存在"));
    
    if (slot.getRemainingSlots() <= 0) {
        throw new RuntimeException("号源已满");
    }
    
    slot.setRemainingSlots(slot.getRemainingSlots() - 1);
    timeSlotRepository.save(slot); // 乐观锁自动检查version
}

3.6.2 预约单号生成逻辑

预约单号格式：GH + 日期(yyyyMMdd) + 6位序号

// 生成预约单号
private String generateAppointmentNo() {
    String dateStr = LocalDate.now().format(
        DateTimeFormatter.ofPattern("yyyyMMdd"));
    String sequence = String.format("%06d", 
        appointmentRepository.countByDate(LocalDate.now()) + 1);
    return "GH" + dateStr + sequence;
}

3.6.3 用户登录失败锁定逻辑

连续登录失败5次后锁定账户30分钟：

// 登录失败处理
public void handleLoginFailure(User user) {
    user.setLoginFailures(user.getLoginFailures() + 1);
    
    if (user.getLoginFailures() >= 5) {
        user.setStatus(UserStatus.LOCKED);
        user.setLockedUntil(LocalDateTime.now().plusMinutes(30));
    }
    
    userRepository.save(user);
}

3.6.4 JPA生命周期回调

使用@PrePersist和@PreUpdate注解自动维护时间戳：

@PrePersist
protected void onCreate() {
    createdAt = LocalDateTime.now();
    updatedAt = LocalDateTime.now();
    if (id == null) {
        id = UUID.randomUUID().toString();
    }
}

@PreUpdate
protected void onUpdate() {
    updatedAt = LocalDateTime.now();
}
