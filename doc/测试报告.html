2 系统实现模块说明

2.1 用户认证模块

2.1.1 描述

用户认证模块负责系统的登录、注册、登出及密码重置功能，支持患者、医生、管理员三种角色。

活动流程：

开始 → 输入手机号/密码 → 格式验证
  ↓
格式正确? --否--> 显示格式错误 → 返回
  ↓是
调用登录API → 验证用户存在?
  ↓
存在? --否--> 显示用户不存在 → 结束
  ↓是
验证密码 → 正确? --否--> 显示密码错误 → 结束
  ↓是
生成JWT Token → 跳转首页 → 结束

2.1.2 主要代码

后端登录接口 (AuthController.java):

@PostMapping("/login")
public ResponseEntity<ApiResponse<LoginResponse>> login(
        @Valid @RequestBody LoginRequest request) {
    LoginResponse response = authService.login(request);
    return ResponseEntity.ok(ApiResponse.success(response));
}

前端登录处理 (Login.vue):

const handleLogin = async () => {
  if (!loginForm.identifier || !loginForm.password) {
    ElMessage.error('请输入手机号和密码');
    return;
  }
  loading.value = true;
  try {
    await userStore.login({
      identifier: loginForm.identifier,
      password: loginForm.password
    });
  } finally {
    loading.value = false;
  }
};

2.2 预约挂号模块

2.2.1 描述

预约挂号模块是系统核心功能，患者可搜索医生、查看排班、创建预约、取消预约。

活动流程：

开始 → 搜索医生 → 选择医生 → 查看排班
  ↓
选择时间段 → 号源充足? --否--> 提示号源已满 → 返回
  ↓是
填写就诊信息 → 提交预约 → 扣减号源 → 生成预约单号
  ↓
发送通知 → 显示预约详情 → 结束

2.2.2 主要代码

@PostMapping
public ApiResponse<AppointmentDetailDTO> createAppointment(
        @Valid @RequestBody CreateAppointmentDTO dto) {
    String userId = (String) SecurityContextHolder
            .getContext().getAuthentication().getPrincipal();
    AppointmentDetailDTO result = 
        appointmentService.createAppointment(userId, dto);
    return ApiResponse.success(result);
}
