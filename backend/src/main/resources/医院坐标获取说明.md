# 医院坐标获取说明

## ⚠️ 重要提示

`add_sample_hospitals.sql` 中的医院名称是真实的，但**坐标（经纬度）可能是估算值，不一定准确**。

## 获取真实坐标的方法

### 方法1：使用高德地图API（推荐）

1. 访问高德地图开放平台：https://lbs.amap.com/
2. 注册账号并创建应用
3. 使用"地理编码"API，将医院地址转换为坐标

示例API调用：
```
https://restapi.amap.com/v3/geocode/geo?address=天津市和平区鞍山道154号&key=YOUR_KEY
```

### 方法2：使用高德地图网页版

1. 打开 https://map.amap.com/
2. 搜索医院名称或地址
3. 点击医院标记，查看坐标
4. 坐标格式：经度,纬度（例如：117.195907,39.104027）

### 方法3：使用百度地图

1. 打开 https://map.baidu.com/
2. 搜索医院地址
3. 右键点击位置，选择"这是哪儿？"
4. 查看坐标（注意：百度坐标需要转换为高德坐标）

## 更新坐标的SQL语句

获取到准确坐标后，使用以下SQL更新：

```sql
-- 更新天津医科大学总医院的坐标
UPDATE hospitals 
SET longitude = 117.195907, latitude = 39.104027
WHERE name = '天津医科大学总医院';

-- 更新其他医院的坐标
-- UPDATE hospitals SET longitude = 经度, latitude = 纬度 WHERE name = '医院名称';
```

## 验证坐标准确性

更新坐标后，可以在高德地图上验证：
1. 访问 https://lbs.amap.com/tools/picker
2. 输入坐标进行定位
3. 确认位置是否与医院实际位置一致

## 注意事项

- 高德地图使用 GCJ-02 坐标系（火星坐标系）
- 如果需要使用其他地图服务，可能需要坐标转换
- 建议定期验证坐标的准确性
