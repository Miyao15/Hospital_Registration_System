# 3D 转场动画说明

## 概述

为 LandingHarmony 页面添加了 Apple 风格的 3D 场景转场效果，实现从 Hero Section 到 Doctors Section 的丝滑过渡。

## 效果描述

### 转场动画流程

1. **Hero Section（初始状态）**
   - 正常显示，完全可见
   - 用户向下滚动

2. **转场开始（滚动到中间）**
   - Hero Section 开始缩小、后退、旋转
   - 透明度逐渐降低
   - 出现金色光晕过渡效果

3. **转场进行中**
   - Hero Section 继续远离（3D 透视）
   - Doctors Section 从远处放大靠近
   - 金色光晕达到最强

4. **转场结束**
   - Hero Section 完全淡出
   - Doctors Section 完全显示
   - 光晕消失

## 技术实现

### 1. 3D 变换参数

**Hero Section（退出）：**
- `scale`: 1 → 0.7（缩小 30%）
- `rotateX`: 0deg → -15deg（向后倾斜）
- `translateZ`: 0px → -500px（远离镜头）
- `opacity`: 1 → 0.3（淡出）

**Doctors Section（进入）：**
- `scale`: 0.7 → 1（放大到正常）
- `rotateX`: 15deg → 0deg（从倾斜到正常）
- `translateZ`: -500px → 0px（靠近镜头）
- `opacity`: 0 → 1（淡入）

### 2. 过渡光晕

- 使用径向渐变创建金色光晕
- 透明度在转场中间达到峰值（30%）
- 缩放效果增强视觉冲击

### 3. 缓动函数

使用 `easeInOutCubic` 缓动函数：
```javascript
t < 0.5 ? 4 * t * t * t : 1 - Math.pow(-2 * t + 2, 3) / 2
```

确保转场开始和结束时平滑，中间加速。

## 触发条件

- **开始触发**：Hero Section 底部到达屏幕中间（50vh）
- **结束触发**：Hero Section 底部到达屏幕上方（20vh）
- **转场区间**：约 30vh 的滚动距离

## 性能优化

1. **GPU 加速**
   - 使用 `transform` 和 `opacity`（GPU 加速属性）
   - 添加 `will-change` 提示浏览器优化
   - 使用 `backface-visibility: hidden` 减少重绘

2. **滚动优化**
   - 使用 `passive: true` 监听滚动
   - 避免在滚动事件中进行复杂计算
   - 使用 `requestAnimationFrame` 优化渲染

3. **3D 上下文**
   - 设置 `perspective: 1000px` 创建 3D 空间
   - 使用 `transform-style: preserve-3d` 保持 3D 效果

## 自定义参数

如需调整转场效果，可修改以下参数：

### 转场距离
```javascript
const transitionStart = windowHeight * 0.5; // 开始位置（50vh）
const transitionEnd = windowHeight * 0.2;   // 结束位置（20vh）
```

### 3D 变换强度
```javascript
const heroScale = 1 - easedProgress * 0.3;      // 缩放幅度
const heroRotateX = easedProgress * -15;        // 旋转角度
const heroTranslateZ = easedProgress * -500;    // 移动距离
```

### 光晕效果
```javascript
const overlayOpacity = Math.sin(easedProgress * Math.PI) * 0.3; // 透明度
const overlayScale = 1 + Math.sin(easedProgress * Math.PI) * 0.5; // 缩放
```

## 扩展建议

### 添加更多转场

可以在其他 Section 之间添加类似效果：

1. Doctors → Stats
2. Stats → Departments
3. Departments → Process

### 不同转场风格

- **翻页效果**：增加 `rotateY` 旋转
- **推拉效果**：只使用 `translateZ`
- **淡入淡出**：只使用 `opacity`
- **扭曲效果**：组合 `rotateX` 和 `rotateY`

### 交互增强

- 添加鼠标视差效果
- 根据滚动速度调整转场速度
- 添加音效（可选）

## 注意事项

1. **性能监控**
   - 在低端设备上可能需要降低效果强度
   - 监控 FPS，确保 60fps 流畅度

2. **移动端适配**
   - 移动端可能需要简化效果
   - 考虑添加 `prefers-reduced-motion` 媒体查询

3. **可访问性**
   - 为运动敏感用户提供关闭选项
   - 确保内容在转场时仍可访问
