# 3D模型旋转角度测试说明

## 当前设置
默认旋转角度：`Math.PI` (180度)

## 如何测试不同角度

打开 `src/components/AIAssistant.vue`，找到这一行：

```vue
:initial-rotation="Math.PI"
```

尝试以下不同的值：

### 角度选项

| 值 | 角度 | 说明 |
|---|---|---|
| `0` | 0° | 默认朝向 |
| `Math.PI / 4` | 45° | 向右转45度 |
| `Math.PI / 2` | 90° | 向右转90度 |
| `Math.PI * 3 / 4` | 135° | 向右转135度 |
| `Math.PI` | 180° | 转身（背对变正面） |
| `Math.PI * 5 / 4` | 225° | 向左转135度 |
| `Math.PI * 3 / 2` | 270° | 向左转90度 |
| `Math.PI * 7 / 4` | 315° | 向左转45度 |
| `-Math.PI / 2` | -90° | 向左转90度（负值） |

## 快速测试步骤

1. **修改旋转角度**
   ```vue
   <!-- 在 AIAssistant.vue 中 -->
   <VRMAvatar 
     :initial-rotation="0"  <!-- 改这里的值 -->
   />
   ```

2. **保存文件**
   - 热重载会自动刷新页面

3. **观察效果**
   - 查看右下角的AI助手
   - 点击打开聊天窗口查看头像

4. **找到正确角度**
   - 记录哪个角度是正面朝向你的
   - 在所有三个位置使用相同的角度

## 三个使用位置

### 1. 悬浮按钮（大）
```vue
<VRMAvatar 
  :model-url="vrmModelUrl"
  :auto-rotate="true"
  :scale="1.2"
  :camera-distance="3.0"
  :camera-height="1.4"
  :initial-rotation="Math.PI"  <!-- 改这里 -->
  class="vrm-avatar"
/>
```

### 2. 聊天窗口头像（中）
```vue
<VRMAvatar 
  :model-url="vrmModelUrl"
  :auto-rotate="false"
  :scale="1.0"
  :initial-rotation="Math.PI"  <!-- 改这里 -->
  class="header-vrm"
/>
```

### 3. 消息头像（小）
```vue
<VRMAvatar 
  :model-url="vrmModelUrl"
  :auto-rotate="false"
  :scale="0.8"
  :initial-rotation="Math.PI"  <!-- 改这里 -->
  class="msg-vrm"
/>
```

## 常见情况

### 如果模型是侧面朝向
- 尝试 `Math.PI / 2` 或 `-Math.PI / 2`

### 如果模型是背面朝向
- 尝试 `Math.PI` (180度)

### 如果模型是斜着的
- 尝试 `Math.PI / 4` 的倍数

## 调试技巧

### 浏览器控制台
打开浏览器控制台（F12），输入：
```javascript
// 查看当前旋转角度（弧度）
console.log('Rotation:', Math.PI);
// 转换为度数
console.log('Degrees:', Math.PI * 180 / Math.PI);
```

### 实时调整
如果想实时调整而不刷新页面，可以在浏览器控制台中：
```javascript
// 假设你能访问到VRM实例
// 这需要在VRMAvatar组件中暴露
vrm.scene.rotation.y = Math.PI / 2; // 尝试不同的值
```

## 推荐测试顺序

1. 先试 `0` - 看默认朝向
2. 再试 `Math.PI` - 看180度转身
3. 如果还不对，试 `Math.PI / 2` - 看90度
4. 如果还不对，试 `-Math.PI / 2` - 看-90度
5. 微调：在正确的基础上 ±0.1 弧度

## 找到正确角度后

1. 记录正确的角度值
2. 在所有三个位置更新
3. 保存文件
4. 测试所有场景（悬浮按钮、聊天窗口、消息）
