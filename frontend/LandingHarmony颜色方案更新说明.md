# LandingHarmony 颜色方案更新说明

## 更新时间
2025-01-05

## 更新内容

已将 LandingHarmony.vue 的颜色方案从蓝紫色（HarmonyOS NEXT风格）改回金黄色（原Landing.vue风格）。

## 颜色变更对照表

### 主色调
| 元素 | 旧颜色（蓝紫色） | 新颜色（金黄色） |
|------|-----------------|-----------------|
| 渐变起始色 | #667EEA | #FFD300 |
| 渐变结束色 | #764BA2 | #FF9800 |
| 强调色 | #818CF8 | #FFD300 |

### 背景色
| 元素 | 旧颜色 | 新颜色 |
|------|--------|--------|
| 页面背景 | 深蓝灰渐变 (#0A0E27 → #111827 → #1F2937) | 奶油色渐变 (#FFF9E5 → #FFFDF5 → #FFF9E5) |
| Header背景 | rgba(10, 14, 39, 0.95) | rgba(255, 249, 229, 0.98) |
| 卡片背景 | rgba(17, 24, 39, 0.6) | rgba(255, 249, 229, 0.6) |

### 文字颜色
| 元素 | 旧颜色 | 新颜色 |
|------|--------|--------|
| 主标题 | #fff | #2A2A2A |
| 副标题 | #9CA3AF | #666 |
| 导航链接 | #fff | #2A2A2A |
| 按钮文字 | #fff | #2A2A2A |

### 装饰元素
| 元素 | 旧颜色 | 新颜色 |
|------|--------|--------|
| 光晕效果 | rgba(102, 126, 234, 0.3) | rgba(255, 211, 0, 0.3) |
| 阴影效果 | rgba(102, 126, 234, 0.4) | rgba(255, 211, 0, 0.4) |
| 边框颜色 | rgba(102, 126, 234, 0.2) | rgba(255, 211, 0, 0.2) |

## 视觉效果

### 整体风格
- **旧风格**: 深色背景 + 蓝紫色渐变，现代科技感
- **新风格**: 浅色背景 + 金黄色渐变，温暖亲和感

### 适用场景
- 金黄色方案更适合医疗健康类应用
- 传达温暖、专业、可信赖的品牌形象
- 与原Landing.vue保持视觉一致性

## 技术细节

### 批量替换命令
```powershell
$content = $content -replace 'rgba\(102, 126, 234', 'rgba(255, 211, 0'
$content = $content -replace 'rgba\(118, 75, 162', 'rgba(255, 152, 0'
$content = $content -replace '#667EEA', '#FFD300'
$content = $content -replace '#764BA2', '#FF9800'
$content = $content -replace '#818CF8', '#FFD300'
```

### CSS变量更新
```css
:root {
  --harmony-gradient-start: #FFD300;  /* 从 #667EEA 改为 #FFD300 */
  --harmony-gradient-end: #FF9800;    /* 从 #764BA2 改为 #FF9800 */
  --harmony-accent: #FFD300;          /* 从 #818CF8 改为 #FFD300 */
}
```

## 注意事项

1. 标题文字现在使用深色 (#2A2A2A)，在浅色背景上更清晰可见
2. 所有按钮和交互元素都使用金黄色渐变
3. 保持了原有的动画效果和交互体验
4. 响应式设计保持不变

## 后续建议

如需再次切换颜色方案，可以：
1. 修改 CSS 变量中的三个主色值
2. 运行批量替换命令
3. 调整文字颜色以确保对比度
