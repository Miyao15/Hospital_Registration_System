# HarmonyOS 风格 Landing 页面

## 访问地址
- 新版HarmonyOS风格：`http://localhost:3000/landing-harmony`
- 原版Landing页面：`http://localhost:3000/landing`

## 设计特点

### 1. 视觉风格
- **深色主题**：黑色背景 + 白色文字，高端大气
- **渐变色彩**：使用红橙渐变作为品牌色（#FF6B6B → #FF8E53）
- **极简设计**：去除复杂装饰，专注内容本身
- **大标题**：超大字号（72px），震撼视觉

### 2. 布局结构
- **全屏Hero区**：100vh高度，居中对齐
- **垂直滚动叙事**：每个section独立讲述一个功能点
- **深浅交替**：黑色/深灰背景交替，增强层次感
- **固定导航栏**：滚动时半透明背景 + 模糊效果

### 3. 交互动效
- **平滑滚动**：smooth scroll behavior
- **悬停效果**：卡片上浮 + 阴影增强
- **按钮动效**：hover时上浮 + 发光阴影
- **渐变动画**：品牌色渐变应用于多处
- **数字计数**：统计数据动态递增效果

### 4. 内容区块

#### Hero Section（黑色背景）
- 全屏大标题
- 简短副标题
- CTA按钮
- 视差装饰元素

#### Doctors Section（深灰背景）
- 医生卡片网格
- 大头像 + 评分
- 预约按钮

#### Stats Section（深灰背景）
- 4个统计数据
- 数字计数动画
- 渐变数字显示

#### Departments Section（黑色背景）
- 8个热门科室
- 图标 + 名称 + 医生数量
- 悬停动画效果

#### Process Section（深灰背景）
- 3步预约流程
- 步骤编号 + 图标
- 箭头连接

#### Testimonials Section（黑色背景）
- 用户真实评价
- 5星评分
- 用户头像 + 姓名 + 日期

#### CTA Section（渐变背景）
- 最终行动号召
- 两个按钮：注册 + 浏览医生
- 浮动背景动画

#### Features Section（黑色背景）
- 3个功能卡片
- 图标 + 标题 + 描述
- 网格布局

#### Footer（黑色背景）
- 3列布局
- 链接 + 版权信息

## 技术实现

### 响应式设计
- 使用CSS Grid自适应布局
- 移动端隐藏导航链接
- 按钮和卡片堆叠显示

### 性能优化
- 使用`passive: true`监听滚动
- 图片懒加载
- 最小化动画效果

### 代码结构
- Vue 3 Composition API
- 单文件组件
- Scoped CSS样式

## 使用建议

1. **适用场景**：
   - 追求高端品牌形象
   - 强调科技感和专业性
   - 目标用户年轻化

2. **不适用场景**：
   - 需要温馨亲切感
   - 目标用户年龄偏大
   - 强调医疗温度

3. **切换方式**：
   - 修改路由默认页面即可
   - 或提供用户选择开关
